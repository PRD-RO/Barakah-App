Barakah – Share, Don’t Waste 🍽️

Barakah is a charitable food-sharing application designed to reduce food waste by connecting food donors with volunteers and charitable organizations in an efficient, organized way.

The system enables individuals, restaurants, and hotels to donate surplus food, while volunteers and charities coordinate collection and distribution to people in need.



Problem Statement

Food waste is a serious issue, while many people still lack access to sufficient food. Existing solutions are fragmented and lack real-time coordination between donors, volunteers, and charities.

Barakah addresses this gap by providing a centralized digital platform that manages food donation requests, pickup coordination, tracking, and feedback.



Project Objectives

- Reduce food waste in communities  
- Simplify the food donation process  
- Connect donors, volunteers, and charities in one system  
- Improve transparency and tracking of donations  
- Encourage social responsibility through technology  



System Overview

The system supports three main user roles:

1. Donor
- Create donation requests  
- Specify food type, quantity, location, and pickup time  
- Upload images of food if needed  
- Track donation status  

2. Volunteer
- View available donation requests  
- Filter requests by location and food type  
- Accept and coordinate pickup with donors  
- Update donation status  

3. Charity Organization
- Register and manage organization profile  
- View incoming donations  
- Coordinate distribution to beneficiaries  
- Communicate with donors and volunteers  



Key Features

- User registration and role selection  
- Donation request management  
- Volunteer assignment and coordination  
- Real-time status tracking (Pending, Picked Up, Delivered)  
- Rating and feedback system  
- Notification and communication support
